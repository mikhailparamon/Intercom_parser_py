# Канонические подкатегории и платформы

**Цель:** ограничить новую разметку согласованными 20/19 подкатегориями и явно показывать покрытие рейтингов.

**Архитектура:** `classification_catalog.py` хранит коды, названия, допустимые категории и правила подтверждения платформ. Версия схемы 2 включает строгую проверку; старые результаты продолжают читаться без автоматической переклассификации.

**Технологии:** Python, pytest, существующие JSON/CSV/Markdown/HTML генераторы.
