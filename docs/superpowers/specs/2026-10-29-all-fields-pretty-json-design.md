# Полный экспорт Intercom и читаемый JSON

## Цель

В режиме `--fields all` сохранять полный ответ Intercom по обращению, а экспорт обращений записывать как читаемый JSON-массив с отступами вместо однострочного JSONL.

## Решения

- Режим `all` сохраняет весь объект, возвращённый `GET /conversations/{id}`, включая персональные данные и вложенные поля, которые ранее отбрасывались белым списком.
- Временные поля по умолчанию преобразуются в ISO 8601 UTC в обоих режимах. `--timezone` принимает IANA-зону или `unix`; последнее сохраняет числовые Unix-времена. В режиме `all` остальные значения и вложенная структура сохраняются как в ответе Intercom.
- Оба режима полей записываются в `conversations.json` как массив JSON-объектов с отступами.
- `analyze_support.py` должен читать новый массив JSON и поддерживать ранее созданные JSONL-выгрузки.
- Каждый запуск сохраняется в уникальном каталоге; повторная выгрузка периода не заменяет предыдущий результат.
- CLI, автоматическая подготовка ChatGPT, документация и тесты обновляются вместе с новым путём и форматом.
- Отбор обращений, manifest, счётчики ошибок, очистка данных для ChatGPT и схема режима `important` остаются прежними.

## Проверка готовности

- Тест подтверждает, что `all` сохраняет неизвестные заранее корневые и вложенные поля, а даты по-прежнему конвертируются.
- Тест подтверждает, что результат является корректным форматированным JSON-массивом в `conversations.json`.
- Режим `important` сохраняет прежний компактный набор полей в новом формате.
- Анализатор подготавливает вход как из массива JSON, так и из прежнего JSONL.
- Полный набор тестов проходит; README описывает новый файл и пример команды.
